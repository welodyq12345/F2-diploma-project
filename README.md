# F2-diploma-project — FinJar

Кваліфікаційний проєкт бакалавра зі спеціальності F2 «Інженерія програмного забезпечення».

**FinJar** — мультивалютна платформа управління персональними та корпоративними фінансами з підтримкою гетерогенних гаманців, автоматизованим розподілом коштів за бюджетними категоріями та LLM-асистентом.

## Структура репозиторію

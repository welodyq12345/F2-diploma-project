## Матриця нефункціональних вимог (NFRs)

| Категорія | Ключове обмеження |
|---|---|
| Продуктивність | REST API: p95 ≤ 200 мс при 300 RPS (читання), p95 ≤ 350 мс при 100 RPS (запис) |
| Асинхронна обробка | Розподіл доходу за баночками ≤ 5 с (p95); at-least-once доставка через Transactional Outbox |
| Безпека | JWT (access 15 хв, refresh 7 діб), Argon2, TLS 1.2+, rate limiting 100 запитів/хв, OWASP ASVS 4.0 L2 |
| Надійність | Інваріант подвійного запису без розбіжностей; SLA 99.5%; RPO ≤ 24 год, RTO ≤ 2 год |
| Якість | Покриття тестами ≥ 70%; SonarQube Quality Gate; Trivy без Critical-вразливостей |
